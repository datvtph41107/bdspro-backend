# User source area

This directory contains the current User runtime/authority host after the Architecture Source Migration V1.

The V1 source migration changes physical source topology only. Runtime service identity and current business semantics remain unchanged.

## Development credentials

Do not hard-code or document development credentials in repository documentation. Use the approved local development setup and seeded development data.

## Architecture note

This directory is not declared to be the final business-module decomposition. Further separation of profile, authentication, authorization, organization, commercial access, and related facts requires fact/owner/invariant/lifecycle proof before source mutation.
