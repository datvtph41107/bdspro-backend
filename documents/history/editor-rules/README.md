# Historical editor rules

Các `.mdc` trong thư mục này là rule của source trước khi developer operating
model BDSPro được chuẩn hóa. Chúng được giữ để tra cứu lịch sử nhưng **không còn
được Cursor áp dụng**.

Canonical active rule nằm tại:

`/.cursor/rules/bdspro-development.mdc`

Không copy rule lịch sử trở lại `.cursor/rules/` nếu chưa đối chiếu với
`documents/DEVELOPMENT-ARCHITECTURE-STANDARD.md`.
