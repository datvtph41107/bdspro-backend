# II.1 Wire - Dependency Injection

## 🎯 Tổng Quan

Wire là công cụ dependency injection của Google, giúp tự động tạo ra code để inject các dependencies trong Go. Trong dự án BDSPro, Wire được sử dụng để quản lý dependencies giữa các layer (handlers, usecases, repositories).

---

## 🔧 Cách Sử Dụng Wire

### **1. Tự Động Generate Wire**

Dự án đã có sẵn script tự động quét và generate wire, không cần thêm thủ công vào `wire.go`:

```bash
# Generate wire cho service cụ thể
make wire <service-name>
# Ví dụ: make wire user

# Hoặc sử dụng script trực tiếp
./script.sh wire <service-name>
```

### **2. Quy Tắc Đặt Tên Hàm Khởi Tạo**

Khi viết các hàm khởi tạo, **BẮT BUỘC** phải tuân theo quy tắc:

```go
// ✅ ĐÚNG - Bắt đầu bằng "New"
func NewUserRepository(db *gorm.DB) repository.UserRepository {
    return &userRepository{db: db}
}

func NewUserUsecase(userRepo repository.UserRepository) usecase.UserUsecase {
    return &userUsecase{userRepo: userRepo}
}

func NewUserHandler(userUsecase usecase.UserUsecase) handler.UserHandler {
    return &userHandler{userUsecase: userUsecase}
}

// ❌ SAI - Không bắt đầu bằng "New"
func CreateUserRepository(db *gorm.DB) repository.UserRepository {
    return &userRepository{db: db}
}

func InitUserUsecase(userRepo repository.UserRepository) usecase.UserUsecase {
    return &userUsecase{userRepo: userRepo}
}
```

### **3. Quy Tắc Tên Hàm Không Trùng**

**LƯU Ý QUAN TRỌNG**: Tất cả các hàm `New...` phải có tên **DUY NHẤT**, không được trùng lặp:

```go
// ✅ ĐÚNG - Tên khác nhau
func NewUserRepository(db *gorm.DB) repository.UserRepository { ... }
func NewUserUsecase(userRepo repository.UserRepository) usecase.UserUsecase { ... }
func NewUserHandler(userUsecase usecase.UserUsecase) handler.UserHandler { ... }

// ❌ SAI - Tên trùng lặp
func NewUserRepository(db *gorm.DB) repository.UserRepository { ... }
func NewUserRepository(cache *redis.Client) repository.UserCacheRepository { ... } // TRÙNG TÊN!
```

## 🔗 Binding Interface với Implementation

### **1. Sử Dụng @bind Comment**

Đối với các struct implement interface, cần thêm comment `@bind:` trước struct:

```go
// @bind: user/internal/repository
type userRepository struct {
    db *gorm.DB
}

func (r *userRepository) GetByID(ctx context.Context, id uint64) (*entity.User, error) {
    // Implementation
}

// @bind: user/internal/usecase  
type userUsecase struct {
    userRepo repository.UserRepository
}

func (u *userUsecase) GetUser(ctx context.Context, id uint64) (*entity.User, error) {
    // Implementation
}

// @bind: user/infrastructure/handler
type userHandler struct {
    userUsecase usecase.UserUsecase
}

func (h *userHandler) GetUser(ctx context.Context, req *userpb.GetUserRequest) (*userpb.GetUserResponse, error) {
    // Implementation
}
```

### **2. Cú Pháp @bind Comment**

```go
// @bind: <service-name>/internal/<layer>
// Ví dụ:
// @bind: user/internal/repository
// @bind: user/internal/usecase
// @bind: user/infrastructure/handler
// @bind: organization/internal/repository
// @bind: bdspro/internal/interface
```

## 📁 Cấu Trúc Wire trong Dự Án

### **1. File wire.go**
```go
//go:build wireinject
// +build wireinject

package wire

import (
    "github.com/google/wire"
    // Import các dependencies
)

//go:generate wire
func InitializeUserHandler() handler.UserHandler {
    wire.Build(
        // Các dependencies sẽ được tự động generate
    )
    return nil
}
```

### **2. File wire_gen.go** (Tự động generate)
```go
// Code generated by Wire. DO NOT EDIT.

//go:generate go run github.com/google/wire/cmd/wire
//go:build !wireinject
// +build !wireinject

package wire

import (
    // Generated code
)

func InitializeUserHandler() handler.UserHandler {
    // Auto-generated dependency injection code
}
```

## 🚀 Workflow Sử Dụng Wire

### **1. Khi Thêm Repository Mới**
```go
// 1. Tạo struct implement interface
// @bind: user/internal/repository
type userProfileRepository struct {
    db *gorm.DB
}

// 2. Viết hàm khởi tạo
func NewUserProfileRepository(db *gorm.DB) repository.UserProfileRepository {
    return &userProfileRepository{db: db}
}

// 3. Generate wire
make wire user
```

### **2. Khi Thêm Usecase Mới**
```go
// 1. Tạo struct implement interface
// @bind: user/internal/usecase
type userProfileUsecase struct {
    userProfileRepo repository.UserProfileRepository
}

// 2. Viết hàm khởi tạo
func NewUserProfileUsecase(userProfileRepo repository.UserProfileRepository) usecase.UserProfileUsecase {
    return &userProfileUsecase{userProfileRepo: userProfileRepo}
}

// 3. Generate wire
make wire user
```

### **3. Khi Thêm Handler Mới**
```go
// 1. Tạo struct implement interface
// @bind: user/infrastructure/handler
type userProfileHandler struct {
    userProfileUsecase usecase.UserProfileUsecase
}

// 2. Viết hàm khởi tạo
func NewUserProfileHandler(userProfileUsecase usecase.UserProfileUsecase) handler.UserProfileHandler {
    return &userProfileHandler{userProfileUsecase: userProfileUsecase}
}

// 3. Generate wire
make wire user
```

## ⚠️ Lưu Ý Quan Trọng

### **1. Thứ Tự Generate**
```bash
# Luôn generate wire sau khi thay đổi dependencies
make wire <service>

# Nếu có lỗi, có thể cần generate lại
make wire <service>
```

### **2. Kiểm Tra Lỗi**
```bash
# Nếu wire generation bị lỗi, kiểm tra:
# 1. Tên hàm New... có trùng không
# 2. @bind comment có đúng format không
# 3. Interface và implementation có match không
```

### **3. Best Practices**
- **Luôn đặt tên hàm bắt đầu bằng "New"**
- **Tên hàm phải duy nhất, không trùng lặp**
- **Thêm @bind comment cho mọi struct implement interface**
- **Generate wire sau mỗi lần thay đổi dependencies**
- **Không chỉnh sửa file wire_gen.go thủ công**

## 🔍 Ví Dụ Thực Tế

### **Repository Layer**
```go
// @bind: user/internal/repository
type userRepository struct {
    db *gorm.DB
}

func NewUserRepository(db *gorm.DB) repository.UserRepository {
    return &userRepository{db: db}
}

// @bind: user/internal/repository
type userProfileRepository struct {
    db *gorm.DB
}

func NewUserProfileRepository(db *gorm.DB) repository.UserProfileRepository {
    return &userProfileRepository{db: db}
}
```

### **Usecase Layer**
```go
// @bind: user/internal/usecase
type userUsecase struct {
    userRepo         repository.UserRepository
    userProfileRepo  repository.UserProfileRepository
}

func NewUserUsecase(
    userRepo repository.UserRepository,
    userProfileRepo repository.UserProfileRepository,
) usecase.UserUsecase {
    return &userUsecase{
        userRepo:        userRepo,
        userProfileRepo: userProfileRepo,
    }
}
```

### **Handler Layer**
```go
// @bind: user/infrastructure/handler
type userHandler struct {
    userUsecase usecase.UserUsecase
}

func NewUserHandler(userUsecase usecase.UserUsecase) handler.UserHandler {
    return &userHandler{userUsecase: userUsecase}
}
```

## 🎯 Tóm Tắt

| Bước | Hành Động | Lệnh |
|------|-----------|------|
| 1 | Viết struct implement interface | - |
| 2 | Thêm @bind comment | `// @bind: service/internal/layer` |
| 3 | Viết hàm New... (tên duy nhất) | `func New...()` |
| 4 | Generate wire | `make wire <service>` |

**Quy tắc vàng**: `New...` + `@bind:` + `make wire` = Dependency Injection hoàn hảo!
